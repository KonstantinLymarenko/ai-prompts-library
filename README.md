# AI Prompts Library

A curated collection of production-ready prompt engineering templates for real-world tasks.

Built from hands-on experience working with Claude and GPT-4 on research, automation, and intelligence workflows.

## Categories

| Folder | Description |
|--------|-------------|
| [`/research`](./research) | OSINT, competitive intelligence, deep-dive research |
| [`/automation`](./automation) | Workflow automation, task decomposition, agent instructions |
| [`/analysis`](./analysis) | Data interpretation, pattern recognition, summarization |
| [`/content`](./content) | Writing, editing, reframing, audience adaptation |

## How to use

Each prompt file contains:
- **Purpose** — what the prompt is designed to do
- **Prompt** — ready to copy-paste, with `{{variables}}` to customize
- **Tips** — how to get better results
- **Example** — sample input/output

## Models tested on

- Claude 3.5 / Claude 3 Opus (Anthropic)
- GPT-4o / GPT-4 Turbo (OpenAI)

*Prompts are opinionated — built for precision and real output, not generic demos.*
